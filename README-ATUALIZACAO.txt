COMO ATUALIZAR O SITE MATILDES REIS

1. TEXTOS, TELEFONES, LINKS E DADOS DOS IMÓVEIS/PRODUTOS
Edite o arquivo: js/conteudo.js

2. FOTOS
Coloque as fotos novas na pasta: imagens/
Use nomes simples, por exemplo:
apartamento1.jpg
apartamento2.jpg
produto1.jpg

3. PARA ATUALIZAR NO GITHUB
- Abra o repositório matildesreis
- Add file > Upload files
- Envie o arquivo/pasta que foi alterado
- Commit changes

4. NÃO ALTERE
- A configuração do GitHub Pages
- O domínio personalizado
- Os registros DNS da HostGator

Observação: o site continua hospedado gratuitamente no GitHub Pages.
